# MediAssist-Healthcare 🏥

AI-powered healthcare assistant platform built to help doctors manage patients, consultations, and medical workflows.

## 🚀 Project Overview

MediAssist-Healthcare is a healthcare management system combining modern backend technologies with AI capabilities.

The project aims to provide:

- Doctor authentication system
- Patient management
- Consultation management
- AI-assisted healthcare support
- Secure medical data handling

## 🛠️ Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication
- bcrypt Password Hashing

### AI
- Ollama
- Llama 3.1
- LangChain

### Tools
- VS Code
- Git & GitHub
- pgAdmin
